# 🚀 Claude کے لیے فل اسٹیک ڈویلپر اسکل

[English](README.md) · **اردو** · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Español](README.es.md)

Claude کو صرف ایک پرامپٹ دیں، اور وہ آپ کے لیے مکمل **ویب سائٹ، ویب ایپ، SaaS، API، موبائل ایپ (اینڈرائیڈ/iOS) یا ڈیسک ٹاپ سافٹ ویئر** بنا دے گا۔ کسی بھی زبان میں لکھیں، Claude اسی زبان میں جواب دے گا۔

**👉 [لائیو ڈیمو دیکھیں](https://jrnoorbaloch.github.io/fullstack-dev-skill/)**

## ✨ یہ کیا بنا سکتا ہے
- 🌐 **ویب سائٹس:** لینڈنگ پیج، پورٹ فولیو، بزنس سائٹ، بلاگ
- 🧩 **ویب ایپس:** SaaS، آن لائن اسٹور، ڈیش بورڈ، بکنگ سسٹم، LMS، چیٹ، AI ایپس
- ⚙️ **بیک اینڈ:** REST API، ڈیٹا بیس، لاگ اِن، پیمنٹس
- 📱 **موبائل:** React Native/Expo، Flutter، یعنی APK، Play Store اور App Store
- 🖥️ **ڈیسک ٹاپ:** POS، انوینٹری، ٹولز، یعنی ‎.exe‎ اور ‎.dmg‎
- 🚀 **ڈیپلائے:** Vercel، Netlify، Supabase، Docker، GitHub Actions

## 📦 اس میں کیا ہے
- **9 ٹیسٹ شدہ ٹیمپلیٹس:** لینڈنگ پیج، Next.js + Supabase SaaS، Expo موبائل ایپ، FastAPI، Python POS، React + shadcn + GSAP، اینیمیٹڈ سلائیڈز، WordPress تھیم، Remotion ویڈیو
- **✨ ورژن 2:** GSAP اینیمیشن، Three.js تھری ڈی، WordPress بلاک تھیمز، HTML پریزنٹیشنز، Remotion ویڈیوز
- **3 اسکرپٹس:** پروجیکٹ بنانا، ٹیسٹ اور بلڈ چیک کرنا، ‎.env.example‎ بنانا
- **14 سلیش کمانڈز** (Claude Code): ‎/new-website‎، ‎/new-webapp‎، ‎/new-mobile‎، ‎/new-desktop‎، ‎/new-api‎، ‎/new-animated-site‎، ‎/new-3d‎، ‎/new-artifact‎، ‎/new-slides‎، ‎/new-video‎، ‎/new-wordpress‎، ‎/fix-bug‎، ‎/review‎، ‎/deploy‎
- **20 گائیڈز:** ڈیزائن، پیمنٹس (JazzCash، Easypaisa، Stripe، COD)، مختلف کاروباروں کے فیچرز، AI، SEO، ٹیسٹنگ
- **60 سے زیادہ تیار پرامپٹس:** [PROMPTS.md](PROMPTS.md) میں

## 📥 انسٹال کرنے کا طریقہ

**Claude ایپ (Pro، Max، Team، Enterprise):**
1. [Releases](https://github.com/jrnoorbaloch/fullstack-dev-skill/releases/latest) سے `fullstack-developer.zip` ڈاؤن لوڈ کریں۔
2. Claude میں **Settings ← Capabilities ← Skills** پر جائیں (Code execution آن ہونا چاہیے)۔
3. **Upload skill** دبائیں، zip فائل منتخب کریں اور اسکل آن کر دیں۔

**ایک کمانڈ سے (npm یا pip):** ‎`npx github:jrnoorbaloch/fullstack-dev-skill install`‎ یا ‎`pip install git+https://github.com/jrnoorbaloch/fullstack-dev-skill`‎ پھر ‎`fullstack-dev-skill install`‎۔ صرف ایک حصہ چاہیے؟ ‎`fullstack-web`‎، ‎`fullstack-mobile`‎، ‎`fullstack-desktop`‎، ‎`fullstack-motion-3d`‎، ‎`fullstack-wordpress`‎، ‎`fullstack-video`‎۔
