# 🚀 Skill de Desarrollador Full-Stack para Claude

[English](README.md) · [اردو](README.ur.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · **Español**

Dale a Claude una sola instrucción y construirá un **sitio web, aplicación web, SaaS, API, app móvil (Android/iOS) o software de escritorio** completo. Escribe en cualquier idioma y Claude responderá en el mismo.

**👉 [Ver demos en vivo](https://jrnoorbaloch.github.io/fullstack-dev-skill/)**

## ✨ Qué puede construir
- 🌐 **Sitios web:** landing pages, portafolios, sitios de empresa, blogs
- 🧩 **Apps web:** SaaS, tiendas online, dashboards, sistemas de reservas, LMS, chat, apps con IA
- ⚙️ **Backend:** APIs REST, bases de datos, autenticación, pagos
- 📱 **Móvil:** React Native/Expo, Flutter → APK / Play Store / App Store
- 🖥️ **Escritorio:** punto de venta, inventario, herramientas → .exe / .dmg
- 🚀 **Despliegue:** Vercel, Netlify, Supabase, Docker, GitHub Actions

## 📦 Qué incluye
- **9 plantillas probadas:** landing page, SaaS con Next.js + Supabase, app Expo, API FastAPI, punto de venta en Python, React + shadcn + GSAP, diapositivas animadas, tema WordPress, vídeo Remotion
- **✨ Versión 2:** animaciones GSAP, 3D con Three.js, temas de bloques WordPress, presentaciones HTML, vídeos Remotion
- **3 scripts:** crear proyecto, verificar tests/build, generar `.env.example`
- **14 comandos** para Claude Code: `/new-website` `/new-webapp` `/new-mobile` `/new-desktop` `/new-api` `/new-animated-site` `/new-3d` `/new-artifact` `/new-slides` `/new-video` `/new-wordpress` `/fix-bug` `/review` `/deploy`
- **20 guías:** diseño, pagos (Stripe, PayPal, contra reembolso y más), sectores, IA, SEO, testing
- **Más de 60 prompts listos:** en [PROMPTS.md](PROMPTS.md)

## 📥 Instalación

**App de Claude (Pro, Max, Team, Enterprise):**
1. Descarga `fullstack-developer.zip` desde [Releases](https://github.com/jrnoorbaloch/fullstack-dev-skill/releases/latest).
2. En Claude ve a **Settings → Capabilities → Skills** (la ejecución de código debe estar activada).
3. Pulsa **Upload skill**, elige el zip y activa la skill.

**Claude Code:**
```bash
/plugin marketplace add jrnoorbaloch/fullstack-dev-skill
/plugin install fullstack-developer@fullstack-dev-skill
```
