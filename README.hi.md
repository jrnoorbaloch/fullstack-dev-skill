# 🚀 Claude के लिए फ़ुल-स्टैक डेवलपर स्किल

[English](README.md) · [اردو](README.ur.md) · **हिन्दी** · [العربية](README.ar.md) · [Español](README.es.md)

Claude को सिर्फ़ एक प्रॉम्प्ट दें और वह आपके लिए पूरी **वेबसाइट, वेब ऐप, SaaS, API, मोबाइल ऐप (Android/iOS) या डेस्कटॉप सॉफ़्टवेयर** बना देगा। किसी भी भाषा में लिखें, Claude उसी भाषा में जवाब देगा।

**👉 [लाइव डेमो देखें](https://jrnoorbaloch.github.io/fullstack-dev-skill/)**

## ✨ यह क्या बना सकता है
- 🌐 **वेबसाइट:** लैंडिंग पेज, पोर्टफ़ोलियो, बिज़नेस साइट, ब्लॉग
- 🧩 **वेब ऐप:** SaaS, ई-कॉमर्स, डैशबोर्ड, बुकिंग सिस्टम, LMS, चैट, AI ऐप
- ⚙️ **बैकएंड:** REST API, डेटाबेस, लॉगिन, पेमेंट
- 📱 **मोबाइल:** React Native/Expo, Flutter → APK / Play Store / App Store
- 🖥️ **डेस्कटॉप:** POS, इन्वेंटरी, टूल्स → .exe / .dmg
- 🚀 **डिप्लॉय:** Vercel, Netlify, Supabase, Docker, GitHub Actions

## 📥 इंस्टॉल कैसे करें

**Claude ऐप (Pro, Max, Team, Enterprise):**
1. [Releases](https://github.com/jrnoorbaloch/fullstack-dev-skill/releases/latest) से `fullstack-developer.zip` डाउनलोड करें।
2. Claude में **Settings → Capabilities → Skills** खोलें (Code execution चालू होना चाहिए)।
3. **Upload skill** दबाएँ, zip चुनें और स्किल चालू करें।

**Claude Code:**
```bash
/plugin marketplace add jrnoorbaloch/fullstack-dev-skill
/plugin install fullstack-developer@fullstack-dev-skill
```
