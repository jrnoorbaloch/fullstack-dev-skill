# 🚀 مهارة المطوّر المتكامل (Full-Stack) لـ Claude

[English](README.md) · [اردو](README.ur.md) · [हिन्दी](README.hi.md) · **العربية** · [Español](README.es.md)

أعطِ Claude طلبًا واحدًا، وسيبني لك **موقعًا إلكترونيًا أو تطبيق ويب أو SaaS أو واجهة API أو تطبيق جوال (أندرويد/iOS) أو برنامج سطح مكتب** كاملًا. اكتب بأي لغة، وسيرد Claude باللغة نفسها.

**👉 [شاهد العروض الحيّة](https://jrnoorbaloch.github.io/fullstack-dev-skill/)**

## ✨ ماذا يمكنه أن يبني
- 🌐 **مواقع:** صفحات هبوط، معارض أعمال، مواقع شركات، مدونات
- 🧩 **تطبيقات ويب:** SaaS، متاجر إلكترونية، لوحات تحكم، أنظمة حجز، منصات تعليم، دردشة، تطبيقات ذكاء اصطناعي
- ⚙️ **الخلفية:** واجهات REST، قواعد بيانات، تسجيل دخول، مدفوعات
- 📱 **الجوال:** React Native/Expo وFlutter، حتى APK وGoogle Play وApp Store
- 🖥️ **سطح المكتب:** نقاط بيع، مخزون، أدوات، حتى ‎.exe‎ و‎.dmg‎
- 🚀 **النشر:** Vercel، Netlify، Supabase، Docker، GitHub Actions

## 📦 المحتويات
- **5 قوالب مختبَرة:** صفحة هبوط، SaaS بـ Next.js + Supabase، تطبيق Expo، واجهة FastAPI، نقطة بيع بـ Python
- **3 سكربتات:** إنشاء مشروع، فحص الاختبارات والبناء، توليد ملف ‎.env.example‎
- **8 أوامر** في Claude Code: ‎/new-website‎، ‎/new-webapp‎، ‎/new-mobile‎، ‎/new-desktop‎، ‎/new-api‎، ‎/fix-bug‎، ‎/review‎، ‎/deploy‎
- **11 دليلًا:** التصميم ودعم RTL، المدفوعات (Stripe، PayPal، Tap، PayTabs، الدفع عند الاستلام)، ميزات القطاعات، الذكاء الاصطناعي، تحسين محركات البحث، الاختبار
- **أكثر من 40 طلبًا جاهزًا:** في [PROMPTS.md](PROMPTS.md)

## 📥 التثبيت

**تطبيق Claude (Pro وMax وTeam وEnterprise):**
1. نزّل `fullstack-developer.zip` من [الإصدارات](https://github.com/jrnoorbaloch/fullstack-dev-skill/releases/latest).
2. في Claude افتح **Settings ← Capabilities ← Skills** (يجب تفعيل تنفيذ الشيفرة).
3. اضغط **Upload skill**، واختر الملف، ثم فعّل المهارة.

**Claude Code:**

<div dir="ltr">

```bash
/plugin marketplace add jrnoorbaloch/fullstack-dev-skill
/plugin install fullstack-developer@fullstack-dev-skill
```
